# Coffee FaceID — планшет для кофе-робота

Android-приложение для Galaxy Tab A9+ на BellaBot. По нажатию кнопки проверяет лицо,
и если человек сегодня ещё не получал кофе, открывает ячейку с кофе. Всё работает локально
на планшете, без интернета.

## Как это работает

1. Человек нажимает «Получить кофе».
2. Камера включается (изображение на экран не выводится) и собирает **3 годных кадра**
   за 7 секунд. Кадр годится, только если:
   - камера не закрыта (кадр не тёмный и не однотонный), света достаточно, нет засветки;
   - в кадре одно крупное лицо (люди далеко на фоне не мешают);
   - лицо достаточно близко, целиком в кадре и смотрит прямо (поворот головы ≤ 15°);
   - видны глаза, нос и рот, они расположены правдоподобно (лицо не закрыто рукой, листком и т.п.);
   - глаза открыты (заодно отсекаются тёмные очки);
   - лицо резкое (дисперсия лапласиана), на месте лица нет ровного пятна.
   Пока что-то не так, на экране подсказка: «Подойдите ближе», «Камера закрыта» и т.д.
3. Три кадра должны совпадать между собой (один и тот же человек, кадр не «поплыл»).
4. Из лица считается отпечаток (MobileFaceNet, 192 числа) и сравнивается с базой.
   Сходство ≥ порога (по умолчанию 0.70) → ✗ «Вы уже получили кофе».
5. Иначе выбирается следующая заполненная ячейка, и плате отправляется команда «открыть».
6. **Только после подтверждения от платы** ячейка помечается пустой, лицо пишется в базу,
   на экране ✓ и сторона ячейки.

## Админка

Только на планшете, скрыта: **5 быстрых нажатий в левый верхний угол экрана**, затем пароль.
Пароль по умолчанию **`1234`**, его нужно сменить в разделе «Прочее».
После 5 неверных паролей вход блокируется на минуту.

- **Ячейки**: две колонки по 10 (левая/правая). Нажатие на ячейку переключает «есть кофе / пусто».
  Есть кнопки «Заполнить всё» и «Очистить всё».
- **База лиц**: количество, статистика за день, «Сбросить базу лиц», автосброс каждый день
  (по умолчанию в 03:00; если планшет был выключен, сброс выполнится при включении).
- **Распознавание**: порог сходства, минимальный размер лица, резкость, допустимый поворот головы.
  Сверху видно, что анализатор сейчас думает о кадре: это помогает подобрать пороги на месте.
- **Выдача**: заглушка или Raspberry Pi, адрес платы, порядок выдачи ячеек.
- **Прочее**: превью лиц, отладочная строка, веб-админка по сети (по умолчанию **выключена**), смена пароля.

## Протокол для Raspberry Pi

Сейчас по умолчанию работает **заглушка**: она «открывает» ячейку за 0,6 с.
В админке можно включить ей имитацию ошибки, чтобы проверить сценарий сбоя.

Чтобы подключить реальную плату, в админке выберите «Raspberry Pi по HTTP» и укажите адрес,
например `http://192.168.1.50:5000`. Планшет отправляет:

```
POST {адрес}/open
Content-Type: application/json
X-Token: <токен>            (только если задан в админке)

{"side": "left", "slot": 3, "request_id": "0f6c…"}
```

- `side`: `"left"` или `"right"`, `slot`: 1–10.
- `request_id` уникален для каждой выдачи. Если запрос с тем же id пришёл повторно,
  плата не должна выдавать второй раз.
- Таймауты: соединение 3 с, ответ 5 с.

Ответ:

- `200 {"status": "ok"}`: ячейка открыта, выдача засчитана.
- Любой другой код или статус (`"empty"`, `"busy"`, `"error"`…) засчитывается как ошибка.
  Человек увидит «Ошибка выдачи», в базу он **не** попадёт, ячейка останется отмеченной полной.

Готовая заготовка сервера для Raspberry Pi (Flask, защита от повторов, systemd) лежит в
[raspberry-pi/](raspberry-pi/README.md). Команде железа нужно заполнить одну функцию `open_cell()`.

## Структура проекта

```
app/src/main/java/com/coffeebot/faceid/
  core/CoffeeService.kt       сценарий нажатия: проверка → поиск в базе → выдача → запись
  core/DailyReset.kt          ежедневный сброс базы лиц
  face/FaceChecker.kt         проверки качества кадра (закрытая камера, ракурс, резкость…)
  face/FaceEmbedder.kt        MobileFaceNet (TFLite) → вектор лица
  face/FrameAnalyzer.kt       кадры с камеры → проверки, сбор годных кадров
  dispense/CoffeeController.kt  заглушка и HTTP-клиент для Raspberry Pi
  data/                       SQLite: лица, ячейки, журнал; настройки
  ui/                         экран выдачи, админка, камера
  web/AdminServer.kt          веб-админка (по умолчанию выключена)
  Kiosk.kt                    режим киоска (Lock Task / Device Owner)
app/src/main/assets/
  mobile_face_net.tflite      модель распознавания лиц
  admin.html                  страница веб-админки
raspberry-pi/                 сервер выдачи для Raspberry Pi
```

## Сборка и установка

Проще всего через **Android Studio**: File → Open → папка проекта, затем Run на подключённом планшете.

Из командной строки нужны JDK 17 и Android SDK (platform 35, build-tools 35).
Укажите путь к SDK в `local.properties` (`sdk.dir=...`) или в переменной `ANDROID_HOME`.

```
./gradlew assembleDebug            # Windows: gradlew.bat assembleDebug
adb install -r app/build/outputs/apk/debug/app-debug.apk
```

На планшете должна быть включена отладка по USB (Параметры разработчика).

## Что стоит знать

- **Порог сходства** надо подобрать на реальных людях. Выше порог: реже отказ «похожему»,
  но проще пройти второй раз. Ниже порог: наоборот.
- Защиты от фото на телефоне (liveness) пока нет. Можно добавить проверку моргания или поворота головы.
- Обработка изображения лица по 152-ФЗ — биометрия. На экране есть строка о согласии,
  база удаляется ежедневно. Юридическую сторону стоит уточнить отдельно.
- Камера включается только после нажатия «Получить кофе» и выключается сразу после проверки.
  Изображение с камеры на экран не выводится.

## Режим киоска

Закрыть приложение можно только в админке («Приложение» → «Закрыть приложение»).

**Без настройки** приложение при запуске закрепляет экран (screen pinning). Это слабая защита:
Android позволяет открепить экран долгим нажатием «Назад» + «Недавние».
В Настройки → Безопасность → «Закрепление приложений» включите «Запрашивать PIN перед откреплением».

**Полная блокировка (рекомендуется для робота)**: приложение становится владельцем устройства (Device Owner).
Тогда кнопки «Домой» и «Недавние», шторка и уведомления недоступны, а приложение
само стартует после перезагрузки.

1. Удалите с планшета все аккаунты (Samsung, Google): Настройки → Учётные записи.
   Иначе Android не разрешит назначить владельца.
2. Выполните на ноутбуке с подключённым планшетом:
   ```
   adb shell dpm set-device-owner com.coffeebot.faceid/.AdminReceiver
   ```
3. Перезапустите приложение. В админке в разделе «Приложение» должно появиться
   «полная блокировка (Device Owner)».

Чтобы снять владельца (например, перед удалением приложения), сначала закройте приложение
из админки, затем выполните:
```
adb shell dpm remove-active-admin com.coffeebot.faceid/.AdminReceiver
```
Debug-сборка разрешает это командой; в release-сборке владельца снимает только сброс планшета.
- Модель `mobile_face_net.tflite` взята из открытого репозитория estebanuri/face_recognition (MobileFaceNet).
